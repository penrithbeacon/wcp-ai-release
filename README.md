# wcp-ai-release

**Release any WCP artefact — guided by AI, from verified build to published production component.**

Give your AI the URL below and it will route you to the right release pipeline:

```
https://github.com/penrithbeacon/wcp-ai-release/blob/main/AI-SKILL.md
```

---

## What this covers

| Have built | Release pipeline |
|-----------|-----------------|
| A widget | [wcp-ai-release-widget](https://github.com/penrithbeacon/wcp-ai-release-widget) |
| A companion agent | [wcp-ai-release-agent](https://github.com/penrithbeacon/wcp-ai-release-agent) |
| Widget + agent together | Both pipelines (agent first) |
| Shipped app (.WCPA → .app) | wcp-ai-release-ship *(coming)* |

## Prerequisite

Complete the build pipeline first:
- Widget: [wcp-ai-build-widget](https://github.com/penrithbeacon/wcp-ai-build-widget)
- Agent: [wcp-ai-build-agent](https://github.com/penrithbeacon/wcp-ai-build-agent)
